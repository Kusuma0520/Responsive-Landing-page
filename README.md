# Responsive-Landing-page
# 🌐 Responsive Landing Page with Interactive Navigation

## 📌 Task Overview

This project demonstrates a **responsive landing page** with an **interactive fixed navigation menu** that changes style on scroll and hover.

---

## 🚀 Features

* ✅ Fixed navigation bar (visible on all pages)
* ✅ Changes background color on scroll
* ✅ Hover effects on menu items
* ✅ Fully responsive design (mobile-friendly)
* ✅ Smooth user experience

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox, Media Queries)
* JavaScript (DOM Manipulation)

---

## 📂 Project Structure

```
├── index.html
├── style.css
└── script.js
```

---

## ⚙️ How It Works

### 🔹 Scroll Effect

* When the user scrolls down, the navbar background changes.
* Implemented using JavaScript `scroll` event.

### 🔹 Hover Effect

* Menu items change color when hovered using CSS.

### 🔹 Fixed Navbar

* Navbar stays at the top using:

```css
position: fixed;
top: 0;
```

---

## 📱 Responsive Design

* Uses CSS media queries for smaller screens.
* Navigation switches to vertical layout on mobile devices.
